# MTX Studio

Strona z polityką prywatności aplikacji **Mistrz Roweru – Karta Rowerowa**:
https://mtxstudiocyber.github.io/mtxstudio/

`index.html` jest generowany z tekstu w aplikacji – nie edytuj go ręcznie. W repozytorium aplikacji
(`karta_rowerowa`): `dart run tool/polityka_html.dart`, potem skopiuj `build/polityka-prywatnosci.html`
tutaj jako `index.html`.
